# Gestion scolaire — Congo-Brazzaville (nom provisoire)

Plateforme web (PWA) de gestion scolaire multi-établissement pour les écoles privées
de Brazzaville et Pointe-Noire : élèves, frais et paiements (Airtel Money / MTN MoMo),
notes et bulletins, absences, espace parents, tableau de bord.
